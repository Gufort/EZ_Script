# 🧠 EZ_Script — Собственный язык программирования

Интерпретируемый язык программирования со статической типизацией, реализованный на Java. Проект создан в образовательных целях в рамках научной (курсовой) работы, темой которой является создание эффективной модели памяти собственного языка программирования.

---

## 🎯 Цель проекта

Основная задача исследования — разработка и сравнительный анализ различных подходов к управлению динамической памятью в интерпретируемых языках программирования:

- **Реализация эффективной модели памяти** — создание структуры данных для отслеживания состояния всех блоков памяти (используется/свободно)
- **Разработка менеджера памяти** — реализация базовых операций аллокации, деаллокации и дефрагментации
- **Сравнение подходов к выделению памяти** — тестирование различных стратегий (First Fit, Best Fit, Worst Fit)
- **Анализ фрагментации** — изучение влияния частых операций allocate/free на распределение свободных блоков
- **Визуализация состояния памяти**

## ✨ Особенности языка

### Типы данных
- `int` — целые числа
- `double` — числа с плавающей точкой
- `bool` — логический тип
- `bi` — большие целые числа (BigInteger)
